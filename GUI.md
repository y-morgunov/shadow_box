# Графический интерфейс

Запуск из каталога проекта:

```sh
./start-gui.sh
```

Или из каталога проекта: `.venv/bin/python gui.py`. Это локальное настольное приложение, браузер и Blender для его работы не нужны. Картинки не отправляются на сервер.

1. Нажмите **Открыть изображение** или оставьте пример с астронавтом.
2. Задайте размер основания, высоту источника над стеной, ширину картинки на стене и параметры стенок. Чёрное означает тень; порог и инверсия позволяют подготовить силуэт.
3. Нажмите **Создать модель и превью**. Генерация идёт в отдельном процессе; можно вращать предыдущую модель или отменить расчёт.
4. Во вкладке **3D-модель** вращайте модель левой кнопкой мыши, масштабируйте колесом. Ctrl + левая кнопка перемещает вид. Кнопка **Сбросить вид** возвращает камеру.
5. Вкладки **Размытие тени** и **Идеальная тень** показывают расчётную проекцию. Первое превью учитывает заданный размер источника. Оно не является фотореалистичным рендером комнаты.
6. **STL сборки** экспортирует последнюю успешно созданную модель. **Папка результата** открывает все файлы: STL, PNG, параметры JSON и контуры стенок.

При старте показывается готовая демонстрационная модель. Изменение настроек не запускает расчёт автоматически: до следующей успешной генерации на экране остаётся предыдущий результат, о чём сообщает строка состояния. Параметры каждого запуска записываются в `request.json` до расчёта, в том числе для диагностики ошибок. Каждому запуску соответствует отдельная папка `output/gui/дата-время`; отменённые расчёты могут оставлять там промежуточные файлы. Перезапуск приложения открывает пример, а не последний проект.

Быстрое превью — 300 × 300 пикселей, точное — 600 × 600. Этот выбор влияет на PNG и время расчёта, но не на детализацию STL. Детализация стенок регулируется отдельно. Центральную часть картинки занимает бокс.

## Установка на другом компьютере

Нужны Python 3.14 и графический сеанс с поддержкой OpenGL:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-gui.txt
.venv/bin/python gui.py
```

На Windows используйте `.venv\Scripts\python.exe`. Linux-скрипт `start-gui.sh` для Windows не нужен. Установка и запуск проверены на Linux x86-64; другие ОС не проверялись.

## Проверки

Обычные тесты геометрии: `.venv/bin/python -m unittest test_radial test_shadow_cube -v`.

Проверка окна, OpenGL, генерации, экспорта и отмены (открывает окно):

```sh
SHADOW_GUI_TEST=1 .venv/bin/python -m unittest test_gui -v
```

Интерфейс использует [Qt for Python](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QProcess.html) для окна и фонового процесса и [PyQtGraph](https://pyqtgraph.readthedocs.io/en/latest/api_reference/3dgraphics/index.html) для интерактивного просмотра модели.

## Расчёт освещения

Добавлены направленный LED, световой поток, угол излучения, фоновый свет и отдельное превью освещения. Кнопка «Тень 1 м» задаёт размеры для первого эксперимента. Подробности и ограничения: [LIGHTING.md](LIGHTING.md).

## Печать на Creality K1, сопло 0,4 мм

После новой генерации нажмите **Комплект для K1…**: ZIP содержит шесть отдельных STL, инструкцию PRINT.md и отчёт проверки. В выпадающем списке над 3D-просмотром можно посмотреть каждую деталь в положении печати. «STL сборки» сохраняет цельную сборку для просмотра; для раздельной печати используйте комплект.

Стенки укладываются наружной поверхностью на стол, стойка — вертикально. Сборка на клей. Габариты каждой детали проверяются под K1 с запасом для каймы. Если детали не входят, приложение сообщает об этом: уменьшите размеры и пересоздайте комплект. Поддержки включаются в слайсере, G-code программа не создаёт.

Параметр «Мин. элемент» убирает слишком тонкие детали рисунка и усиливает соединения. Нижний предел автоматически согласуется с соплом и сужением стенок; итоговая величина записывается в отчёт. Изменённые профили используются в модели и превью. Подробности: [PRINTING.md](PRINTING.md).
# Сглаживание контуров

«Сглаживание краёв, мм» меняет геометрию стенок и экспортируемые STL, а также превью тени. По умолчанию — 0,15 мм; 0 отключает сглаживание. После изменения пересоздайте модель. Более сильное сглаживание убирает мелкие детали и может закрывать маленькие отверстия. Значение задано на стенке короба, а не на проекции. После сглаживания выполняются фильтр минимального элемента и добавление перемычек. Ранее сохранённые модели автоматически не меняются.

## Настройки и пресеты

Параметры, инверсия, режим освещения, качество превью и путь к исходнику автоматически сохраняются при изменении и восстанавливаются при следующем запуске. На Linux файл обычно находится в `~/.config/ShadowCube/Constructor.conf` (учитывается `XDG_CONFIG_HOME`). Если исходник удалён или перенесён, приложение сообщает об этом и предлагает выбрать изображение. Готовая модель автоматически не пересчитывается: при запуске показан пример, после восстановления настроек нажмите «Создать модель и превью».

Кнопки над параметрами:

- **Превью** — детализация стенок 80, превью 300 px: быстрый подбор композиции.
- **Для печати** — детализация стенок 600, превью 600 px: более подробная геометрия, расчёт дольше. Проверку в слайсере этот режим не заменяет.
- **Сохранить настройки… / Загрузить…** — JSON-файлы для своих пресетов. Они содержат параметры и путь к исходнику, но не само изображение и не STL.

Пресеты качества меняют только детализацию и разрешение превью. Размеры, освещение, минимальный элемент и установленное сглаживание сохраняются. Значение сглаживания для нового набора настроек — 0,15 мм; сохранённое пользователем значение имеет приоритет. После смены пресета пересоздайте модель перед экспортом: предыдущий результат остаётся на экране до успешного завершения генерации.

Положение короба внутри картинки задают «Центр короба X, %» и «Центр короба Y, %»
(CLI: `--box-x`, `--box-y`). Ноль — центр, плюс X — вправо, плюс Y — вниз.
Например, Y = 14 располагает центр основания на 64% высоты изображения.
Диапазон −40…40%; основание должно целиком помещаться в картинке.
Светодиод и стойка остаются по центру основания; меняются рисунки стенок,
область расчёта тени и освещения. Смещение сохраняется вместе с настройками.
На исходнике с астронавтом начальная настройка: X = 0, Y = 14.
Размер чёрного прямоугольника на исходнике не меняет физический размер основания.

### Поддержка desktop-кода

`gui.py` отвечает за Qt-виджеты, QProcess и просмотр результатов. В `gui_settings.py` находятся диапазоны и значения параметров, проверка JSON настроек v1 и подготовка аргументов генератора; этот модуль не требует Qt. Его проверки запускаются командой `.venv/bin/python -m unittest test_gui.SettingsTest -v` без графической сессии. Полная GUI-проверка: `SHADOW_GUI_TEST=1 .venv/bin/python -m unittest test_gui -v`. План разделения записан в `GUI_REFACTOR_PLAN.md`.

Соединительные перемычки можно отключить отдельным флажком. Тогда STL и ZIP сохраняют отдельные фрагменты рисунка; их необходимо закрепить при сборке. Поддержки, создаваемые слайсером, настраиваются отдельно в слайсере.

«Мин. элемент» теперь допускает 0: фильтр выключен, автоматического увеличения под сопло нет. По умолчанию фильтр выключен, детализация стенок — 360, сглаживание — 0,15 мм. Для особо тонких деталей можно поставить сглаживание 0 и детализацию 600–2000; проверьте слои в слайсере.

Диапазоны общие с CLI и веб-версией: основание 20–1000 мм, высота 20–2000 мм, картинка 21–100000 мм, стенки 0,1–30 мм, детализация 20–2000, сглаживание 0–10 мм, минимальный элемент 0–20 мм, перемычки 0,05–20 мм, смещения ±49%. Картинка должна быть больше основания, короб должен помещаться внутри неё, толщина должна быть меньше половины основания, высоты должно хватать для нижней рейки. Прежнего ограничения картинки в 2–15 размеров основания нет.
