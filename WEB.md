# Веб-конструктор теневой лампы

Веб-версия использует тот же `radial_shadow.py`: настройки геометрии, смещение короба, освещение, сглаживание 0,15 мм, комплект шести деталей K1. Интерфейс на русском: загрузка изображения, пример с астронавтом, пресеты «Превью» (80 / 300 px) и «Для печати» (600 / 600 px), JSON настроек, этапы расчёта и отмена, три превью, интерактивная 3D-модель сборки и отдельных деталей, STL и ZIP. Просмотр модели: перетаскивание мышью/пальцем, масштаб колесом. Все скрипты локальные, CDN и Node не нужны.

Настройки сохраняются в localStorage браузера, изображения — только на сервере на время жизни результата. JSON совместим с настройками настольного интерфейса; путь к локальному изображению из JSON не читается сервером. После перезагрузки страницы выберите файл снова для нового расчёта. Последний результат восстанавливается по идентификатору, пока он хранится на сервере.

## Локальный запуск

Python 3.14 и Linux x86-64 — проверенное окружение приложения. Из каталога проекта:

```sh
python3.14 -m venv .venv
.venv/bin/pip install -r requirements-web.txt
read -rs SHADOW_PASSWORD
export SHADOW_PASSWORD
export SHADOW_ORIGIN=http://localhost:8080
.venv/bin/python -m web.server
```

Введите пароль длиной не менее 16 символов (команда read не выводит его). Откройте `http://localhost:8080`, войдите этим паролем. По умолчанию сервис слушает только 127.0.0.1. Если используете адрес `127.0.0.1` в браузере, задайте точно `SHADOW_ORIGIN=http://127.0.0.1:8080`. Origin должен совпадать со схемой, именем и портом браузера.

## Сервер в интернете

Это приложение для **одного владельца с общим паролем**, не многопользовательский сервис: все вошедшие могут открыть сохранённые задачи по их идентификатору и отменить текущую задачу. Смена пароля требует перезапуска; перезапуск сбрасывает сессии. Для публичной регистрации пользователей нужна отдельная система учётных записей/квот.

В Python `http.server` нет полноценного промышленного HTTP-фронтенда; наружу публикуйте **только reverse proxy с TLS**, оставляя порт приложения на loopback. [Документация Python](https://docs.python.org/3/library/http.server.html). Ниже вариант Docker Compose с Caddy, установленным на хосте. Docker, домен и TLS-сертификат на вашей машине автоматически не настраиваются.

1. Скопируйте проект на сервер. Создайте `.env` рядом с `compose.yaml`, задайте `chmod 600 .env`; не коммитьте файл. Содержимое:

   ```dotenv
   SHADOW_PASSWORD=длинный-случайный-пароль-замените
   SHADOW_ORIGIN=https://lamp.example.com
   ```

   Для случайного пароля подойдёт `openssl rand -hex 24`. Убедитесь, что секрет не попадает в Git. Compose читает эти переменные из `.env`: [документация Docker](https://docs.docker.com/compose/how-tos/environment-variables/set-environment-variables/).

2. Выполните `docker compose up -d --build`. Образ не содержит Qt, работает от непривилегированного пользователя. Порт 8080 опубликован только на 127.0.0.1; лимиты — 2 CPU / 2 ГБ RAM / 128 процессов. Для сложных изображений при нехватке памяти увеличьте лимит. Образ требует наличия binary wheels зависимостей для архитектуры сервера; сборка с `--only-binary` завершится ошибкой, если их нет.

3. Направьте DNS домена на сервер, разрешите TCP 80/443 и настройте Caddy на хосте:

   ```caddyfile
   lamp.example.com {
       request_body {
           max_size 14MB
       }
       reverse_proxy 127.0.0.1:8080
   }
   ```

   [Caddy автоматически получает сертификат](https://caddyserver.com/docs/automatic-https) для вашего домена; [лимит тела запроса](https://caddyserver.com/docs/caddyfile/directives/request_body) ограничивает загрузки. При HTTPS cookie входа помечается Secure. Не ставьте приложение под подпуть: маршруты рассчитаны на корень домена. Для nginx используйте эквивалентный reverse proxy с `client_max_body_size 14m` и TLS. Не публикуйте 8080 напрямую и не меняйте привязку Compose на `0.0.0.0`.

## Ограничения и данные

- Одна генерация одновременно, без очереди; до 16 одновременных HTTP-запросов. Таймаут чтения — 15 секунд. Долгий расчёт выполняется отдельно; интерфейс опрашивает состояние каждую секунду.
- Загрузка до 10 МБ и 16 мегапикселей. Приложение декодирует и сохраняет PNG, не использует имя/путь пользователя. JSON-запрос ограничен 14 МБ с учётом base64.
- Таймаут генерации по умолчанию 900 секунд (`SHADOW_TIMEOUT`). Отмена и таймаут завершают subprocess.
- Хранятся до восьми последних задач. Перед новой задачей удаляются старые результаты, если суммарный объём превысил 512 МБ. Размер активного результата не ограничивается отдельно: лимит диска/квота volume на сервере остаётся задачей администратора. При перезапуске UUID-каталоги результатов удаляются. Скачивайте нужные STL/ZIP заранее.
- `SHADOW_DATA` — каталог данных (по умолчанию `output/web`). Не направляйте его на каталог с посторонними UUID-папками. Compose использует отдельный volume.
- Сессии живут сутки, cookie HttpOnly/SameSite=Strict, изменения проверяют Origin и CSRF. Вход ограничен 10 попытками в минуту на весь экземпляр.
- Физическая печать, нагрев LED и точность световой картины не проверены. Корпус не содержит крепления конкретного радиатора/LED. Предупреждения расчёта доступны в UI и комплекте ZIP.

Проверка API и настоящей генерации: `.venv/bin/python -m unittest test_web -v`. Наличие binary wheels всех семи зависимостей для CPython 3.14 / manylinux x86-64 проверено через pip download. Docker-сборку и выпуск TLS нужно проверить на целевом сервере: локально Docker отсутствует.

## Проверка интерфейса в Chromium

Дополнительная проверка для разработки (Playwright не нужен на сервере):

```sh
.venv/bin/pip install playwright
.venv/bin/python -m playwright install chromium
SHADOW_BROWSER_TEST=1 .venv/bin/python -m unittest test_web_browser -v
```

Тест сам запускает временный сервер на loopback: проверяет вход, допустимость
значений формы, генерацию, превью, скачивание ZIP, отмену следующей задачи,
восстановление настроек и результата, отсутствие ошибок JavaScript и
горизонтальной прокрутки при ширине 390 px.

Настройки геометрии используют общие с CLI и настольным приложением диапазоны из `parameter_specs.py` (детализация до 2000, сглаживание 0–10 мм, минимальный элемент 0–20 мм). Значение минимального элемента 0 отключает фильтрацию. Автоматического увеличения элементов под сопло нет. Флажок «Соединительные перемычки» отключает соединение островков изображения; в этом случае готовое изделие содержит отдельные фрагменты, требующие крепления. Настройка сохраняется в браузере и JSON (`supports: false`); старые JSON включают перемычки по умолчанию. Диапазон размеров картинки больше не привязан к 2–15 размерам основания; физические ограничения взаимного расположения сохраняются. Большая детализация увеличивает время расчёта; серверный таймаут продолжает действовать.
